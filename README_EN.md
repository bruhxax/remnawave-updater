# 🌊 Remnawave Updater

**CLI for fast and safe updates of Remnawave Panel, Nodes and Subscription Page.**

[Русский](README.md) · [MIT License](LICENSE)

</div>

## Install

```bash
git clone https://github.com/bruhxax/remnawave-updater.git
cd remnawave-updater
sudo ./install.sh
```

## Run

```bash
updater
```

## Update Updater

```bash
cd ~/remnawave-updater
git pull
sudo ./install.sh --no-setup
```

Panel settings, API token and SSH keys are preserved.
